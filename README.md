# Hôtel Élégance — Site vitrine

Task 3 du programme **Future Interns — Full Stack Web Development**.
Site vitrine one-page pour un établissement hôtelier fictif basé à Lomé, Togo,
construit pour démontrer un cas réel de site pour une entreprise locale (thème "Local Business Website & Live Pitch").

## Stack
HTML5 / CSS3 (design système emeraude & laiton, police Fraunces + Work Sans) / JavaScript vanilla.

## Structure
```
hotel-elegance/
├── index.html
├── css/style.css
└── js/script.js
```

## Fonctionnalités
- Page d'accueil avec présentation de l'hôtel, chiffres clés
- Section "L'expérience" (histoire, accueil, restauration, bien-être)
- Trois formules d'hébergement avec tarifs indicatifs
- Grille de services / équipements
- Galerie d'ambiance
- Témoignages clients
- Formulaire de réservation avec validation des dates côté client
  (conçu pour transmettre ses données au Mini CRM du Task 2)

## Aperçu
Ouvrir `index.html` dans un navigateur — aucune dépendance serveur nécessaire.
